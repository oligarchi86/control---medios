# Control de Medios v6
Versión con fotografías de hasta 20 MB de archivo original. Las imágenes se redimensionan y comprimen automáticamente antes de guardarse para evitar llenar el almacenamiento del teléfono.
Incluye inventario, usuarios/roles, contraseñas, fotos, ubicaciones, movimientos, préstamos/devoluciones, historial, QR, filtros, CSV y copias de seguridad.
