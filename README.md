# Control de Medios v5 — completa

Aplicación web/PWA local para inventario de medios.

Incluye:
- Usuarios con roles Administrador, Operador y Consulta.
- Cambio de contraseña.
- Alta, edición y fotografía desde el teléfono.
- Ubicaciones administrables.
- Movimientos con responsable y observación.
- Préstamos y devoluciones con responsable, destino y fecha prevista.
- Historial por equipo y auditoría general.
- QR individual y descarga del código.
- Búsqueda y filtros.
- Exportación de inventario e historial a CSV.
- Copia de seguridad y restauración.
- Migración automática de datos de versiones anteriores.

Usuario inicial: admin
Contraseña inicial: admin123

Nota: esta versión guarda los datos localmente en el navegador del dispositivo. Para varios teléfonos con una base de datos común hay que conectar después una API/servidor central.
